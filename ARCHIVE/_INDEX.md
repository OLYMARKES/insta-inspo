## Как искать тексты

### По дате (Instagram)
Файлы названы по датам: `YYYY-MM-DD.md`
```
instagram/ig_captions_md/2023-05-15.md
instagram/ig_captions_md/2019-12-31__2.md  (второй пост за день)
```

### По теме
1. **Зависимость/трезвость**: `digests/ig_addiction_sobriety_posts.md` — готовая подборка
2. **Лучшее за год**: `digests/2025_year_3lines_bestof_ig_tg.md`
3. **Книги**: `books/` — полные тексты

### Поиск по ключевому слову
Используй grep/ripgrep по папке:
```bash
grep -r "трезвость" ARCHIVE/instagram/
grep -r "детство" ARCHIVE/books/
```

## Форматы файлов

| Расширение | Что это | Как читать |
|------------|---------|------------|
| `.md` | Markdown-текст | Читать напрямую |
| `.txt` | Чистый текст | Читать напрямую |
| `.json` | Структурированные данные | Парсить как JSON |
| `.html` | HTML-экспорты | Открыть в браузере или парсить |
| `.pages` | Apple Pages | Нужен macOS / Pages |
| `.docx` | Word | Нужен Word / конвертер |
