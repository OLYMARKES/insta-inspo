# Дурге 1–2–3 — ветка книги (автобиографично)

Эта папка — “узел” про книгу **«Дурге 1–2–3»**: что это за текст, как он устроен, как он звучит, и какие **артефакты** (образы/референсы/формулы) можно использовать дальше в письме и жизни.

## Файлы

- `10_description.md` — короткое описание книги (о чём она, зачем, кому).
- `20_style.md` — разбор голоса/приёмов/ритма/лексики (как писать “в этом режиме”).
- `30_plot_and_structure.md` — структура, сюжетные дуги, сквозные линии и “как читать”.
- `40_artifacts_for_writing_and_life.md` — артефакты: музыка, места, предметы, формулы, образы, “домашки”.
- `50_pull_quotes.md` — подборка цитат‑якорей (для каруселей/подписей/референсов).
