## ПРАВИЛА ДЛЯ АГЕНТА

### Перед любой задачей
1. Прочитай этот файл (START.md)
2. Если нужен стиль → `STYLE/voice.md`
3. Если нужен контекст → `CONTEXT/bio.md`
4. Если нужны тексты → `ARCHIVE/_INDEX.md`

### Жёсткие правила
- **Не выдумывай факты** — если не знаешь, спроси или найди в ARCHIVE/
- **Не импровизируй стиль** — бери из STYLE/
- **Соблюдай границы** — читай секцию "Границы публичности"
- **Одна мысль = один текст** — не перегружай

### Формула текста Ольги
```
Деталь/сцена → чувство → смысл → (бережный шаг / вопрос)
```

### Чего НЕ делать
- Глянцевые мотивационные клише ("поверь в себя", "выйди из зоны комфорта")
- Морализаторство и осуждение
- Обещания гарантий
- Использование стыда/страха как инструмента

### Если чего-то не хватает
Лучше задай 2-5 коротких вопросов, чем напиши "красиво, но не про неё".
