# Task Protocol — правила выполнения задач в этом workspace

## 1) Перед началом любой задачи

1) Прочитай: `00_AGENT/START_HERE.md`  
2) Если задача “про голос/текст”: дополнительно `00_AGENT/TONE_OF_VOICE.md`  
3) Если задача “про Ольгу/биографию/детство”: `00_AGENT/PROFILE.md` + первичные источники из `START_HERE`

## 2) Как работать с фактами

- **Факт = есть в файле‑источнике.**  
- Если факт важен, а в источниках есть противоречия — **задай уточняющий вопрос** и пометь “нужно уточнить”.
- Не подменяй реальность “красивой версией”. Здесь ценится документальность.

## 3) Границы и безопасность

- По умолчанию: бережно с детьми (без лишних идентификаторов/деталей).
- Чувствительные темы (утрата, зависимость, секс, отношения/формат семьи) — **только в заранее согласованных границах**.
- Если границы не определены — спроси: “что можно/что нельзя”.

## 4) Правила создания новых файлов

Перед созданием файла спроси себя:
- **зачем файл** и куда он должен жить (контекст/стиль/идеи/анализ/черновики)?
- есть ли уже шаблон в `05_DRAFTS/templates/` или `04_ANALYSIS/templates/`?

Конвенции:
- Не плодить дубли: если это уточнение к существующему — **правь существующий** файл, а не создавай новый.
- Названия файлов: коротко, по смыслу, латиница/подчёркивания в тех папках, где уже так принято.
- Внутри файла: в начале 1–2 строки “что это/зачем”.

## 5) Формат “ответа” в тексте

Если это документ/пост:
- сначала смысл, потом красота
- короткие абзацы, ясные связки
- без глянца, без “продающих” манипуляций

## 6) Когда задавать вопросы

Задавай вопросы, если:
- в задаче есть **публичность/границы** (что можно говорить)
- нужно назвать **место/людей/проекты**, а это может быть чувствительно
- есть противоречия по фактам (Москва/Бали, список проектов, формулировки)

Шаблон (2–5 вопросов максимум):
- “Насколько личным можно быть (0–10)?”
- “Какие детали точно нельзя?”
- “Как правильно называть проект/где ссылка?”
