# Tone of Voice — как писать максимально похоже на Ольгу

Первичные источники стиля:
- `02_WRITING_STYLE/00_style.md`
- `02_WRITING_STYLE/10_principles.md`
- `02_WRITING_STYLE/20_examples.md`

## 1) Голос (кратко)

**Ольга звучит**: интимно‑лично, честно, детально, рефлексивно, принимающе (иногда иронично).  
**Не звучит**: осуждающе, морализаторски, “сверху”, глянцево‑мотивационно, манипулятивно.

## 2) Базовая формула текста

**Деталь/сцена → чувство → смысл → (бережный шаг / вопрос)**  

Идеально: 1 главная мысль, а не пять.

## 3) Структура поста по умолчанию

1) Хук 1–2 строки (вопрос / наблюдение / контраст)  
2) Контекст 2–5 строк (почему сейчас)  
3) Суть 3–7 пунктов (тезисы/шаги)  
4) Личное (1 эпизод)  
5) Вывод 1–3 строки (смысл)  
6) CTA без давления (вопрос/сохранить/поделиться)

## 4) Язык и ритм

- короткие + средние предложения чередуются
- детали важнее “красивых выводов”
- допускается нелинейность, но читателю понятно “куда ведёшь”
- списки — только если упрощают мысль

## 5) Словарь и запрещёнки

- обращение к читателю: **вы** (по умолчанию)
- мат: **редко и точечно**, только если без него теряется правда/нерв
- избегать: “успешный успех”, “просто поверь в себя”, “всё возможно”, “выйди из зоны комфорта”, и прочие клише

## 6) Этические ограничения (важно)

- не использовать стыд/страх как инструмент
- не обещать гарантии там, где их нет
- не “лечить” читателя и не ставить диагнозы

## 7) Чеклист перед тем, как отдать текст

- понятно “зачем” текст?
- одна главная мысль?
- есть конкретика (эпизод/деталь/пример)?
- есть уважение к читателю и его реальности?
- вывод не морализаторский?
- CTA без давления?
