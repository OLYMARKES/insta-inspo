# Откуда ноги растут — ветка книги (автобиографично)

Эта папка — “узел” по книге **«Откуда ноги растут»**: о чём она, как устроена, как звучит, и какие **артефакты** (образы/места/референсы/формулы) можно носить дальше в письме и жизни.

## Файлы

- `10_description.md` — короткое описание книги (о чём, для кого, зачем).
- `20_style.md` — разбор голоса/ритма/приёмов (как писать “в этом режиме”).
- `30_plot_and_structure.md` — сюжет/структура/сквозные линии.
- `40_artifacts_for_writing_and_life.md` — артефакты: места, предметы, ритуалы, культурные маркеры, формулы.
- `50_pull_quotes.md` — цитаты‑якоря (для каруселей/подписей/эпиграфов).
